# Stage 3 数据集变更说明（逐项）

版本：`test_tasks_v2`（revision 2）；`dev_tasks_v1` 与 `prompt_template.json`
同步修订。原 Stage 2 冻结清单 `datasets/frozen_hashes.json` 保留不动；
Stage 3 新冻结清单为 `datasets/frozen_hashes_stage3.json`。
正式运行开始后不再按结果调整任何规则。

| 条目 | 变更 | 原因 | 对评分的影响 |
| --- | --- | --- | --- |
| test-012 | 金标 `38.5元` → `38.5`；字段名改为"本笔消费金额（元）" | 原金标与模板"数值类字段只输出数字本身"的无单位要求不一致（Stage 2 遗留缺陷，开发期未覆盖到此题）；单位信息移入字段名避免歧义 | 输出 `38.5` 判对；`38.5元` 现按口径判错（此前相反） |
| prompt_template（single_field） | 明确单位/标点规则：数值类只输出数字（字段名标明单位）；日期时间按原文表述；不增加答案外标点但保留答案内部必要字符（连字符/小数点） | 消除"不要加单位、标点"的歧义——原措辞可能被理解为要删除电话连字符等答案内部字符 | 影响所有单字段题的判定边界（澄清而非放宽） |
| test-020 | 字段 `起飞时间` → `起飞时间（含日期）`（fields 与 gold 键同步） | 原文"3月2日8:15"，仅问"起飞时间"存在只答时刻或含日期两种合理解，唯一答案歧义 | 输出须含日期（如 `3月2日8:15`）才判对 |
| test-029 | 字段 `银行` → `银行名称（不含支行）`（fields 与 gold 键同步） | 原文含"中国银行府前支行"，"银行"存在答成支行的歧义 | 输出 `中国银行` 判对；含支行名判错 |
| test-006 | note 明确"含简单推导（80-73），不是纯原文抽取" | 如实标注题目性质；组成仍计入单字段抽取 15 条 | 评分口径不变 |
| test-023 | note 预注册严格口径：科室金标 `骨科`；输出`骨科门诊`判错 | 原文"骨科门诊"，需唯一答案；选择科室名为答案并冻结，不因模型表现放宽 | 明确了边界案例的判定 |
| dataset_id | `test_tasks_v1` → `test_tasks_v2`（revision 2） | 版本化管理 | — |

未改动：10 条开发题（题面与金标）、50 条正式题的输入文本、15/15/10/10 组成、
评分器三档口径、JSON 解析规则。JSON 重复键与非标准数值（NaN/Infinity）的
预注册口径：采用 Python `json.loads` 语义（重复键后者覆盖前者；NaN/Infinity
可解析并参与比较），已记录于评分器文档头并有对应测试。
