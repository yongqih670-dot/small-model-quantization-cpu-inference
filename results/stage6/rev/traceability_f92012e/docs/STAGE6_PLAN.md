## 2. 假设（预注册）

**A 标签位置**：三量化版本分类输出主要跟随候选标签**显示位置**（首选位置 0），
而非语义判定。若两轮换下选择与位置无关且语义答案稳定，则假设不成立。

**B JSON 格式**：围栏行为对格式要求强化存在剂量响应：J1（明确格式要求）相对 J0
降低围栏率，J2（J1+示例）相对 J1 进一步降低。J2 相对 J1 的变化不能单独归因于
示例内容（提示长度同时变化）；格式收益与内容变化分开报告，内容退化必须报告。

  金标绑定标签含义不随位置改变；模板无编号。每题 2 序使每个标签在位置 0/1 各一次。
- B 插入文字与位置冻结于 `scripts/stage6_build_variants.py`：
  J1 在「要求」段末行之后插入

  J0 ⊂ J1 ⊂ J2 纯插入性质逐字节校验。

## 5. 指标与判定（预注册）

**分支 A**（按题配对，不以变体扩充样本量）：
- **首要**：选择显示位置 0 标签的比例（每模型 n=20，Wilson 95% CI）。
- 次要：位置选择分布（0/1/不可映射）；原评分器三档正确率（rot0/rot1 分列）；
  同题两轮换下语义答案恒定性；输出是否随首标签变化。
- 映射规则：输出 → 该请求显示的候选标签，strip() 精确相等，否则 normalize_text
  相等，否则不可映射；不允许宽松解析提高正确率。
- rot0 vs rot1 正确率精确 McNemar（预期净效应可为零而位置跟随完全成立，
  故位置比例为首要指标）。

**分支 B**（按题配对）：
- **首要**：每模型×条件的围栏比例、直接可解析比例（parse_method=direct 且为对象）、
  原评分器格式/内容/联合正确率。
- 次要：逐题转移（错误→正确 / 正确→错误，格式/内容/联合；J0→J1、J1→J2）；
  completion_tokens 分布与截断数；代表性原始输出。
- 统计：精确 McNemar + 族内 Holm 校正（每模型×每指标族 3 次比较）；
  小样本强调效应大小与不确定性，不强求显著；全部为事后探索性。
