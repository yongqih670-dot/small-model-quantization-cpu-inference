# Stage 3　四模型质量配对补测

## 对照范围

同一台 Ryzen 9 9955HX，官方 Windows CPU b11347。原 Stage 3 冻结的提示、配置及评分器原样使用。Q4_K_M、Q5_K_M、Q8_0 和 Qwen 官方 FP16 统一来自 GGUF revision 9217f5db79a29953eb74d5343926648285ec7e67。权重采用 SHA256 门禁。FP16 缺失、哈希不匹配或任一模型的分词器、聊天模板或实际输入不一致时暂停正式采集。

## 题库与排程

640 条新编中文短任务由 640 条分别写作的原始情境构成。四题型各 160。开发试跑题独立编写。抽取字段与题意在原文对应，JSON 缺失值用 null；分类在八个标签域各自平衡金标与正确标签显示位置；规范化明确写明操作和输出形式。使用八个二分类域以及告示、工单、对话、日志、档案、发货文书等多种文书风格。相近内容以规范化后的字符片段查重，同时审查故事及规则，避免用同一原始情境的多条变体扩充分母。数据是独立编写的合成评测材料，场景和姓名均为示例。

使用冻结种子分成 16 批，每批各题型 10 道。按四种平衡顺序轮换每批中的四模型，单模型启动一次并顺序完成本批；同题四模型消息逐字一致，预期 2,560 条正式请求。各服务沿用原预热及两次缓存检查。每题只发送一次正式请求；超时恢复时先确认 slot 已释放。超时、HTTP 失败、缓存检查错误及截断按未通过计。服务无法继续时本批剩余请求显式标为未尝试。保存逐条实际覆盖、逐课目首试输出和供电记录。后台以预演阶段验证的相同规则在正式阶段逐题核对渲染和分词结果。

## 主分析与完整性

每题联合正确为 0 或 1。以同题 Q4 减 FP16 的差值 −1、0、+1 为样本，四题型各占四分之一。方差为各层配对样本方差除以层内配对数，再以层权重平方加总。使用 Welch–Satterthwaite 自由度的 Student t 区间，报告单侧 95% 下限和双侧 95% 区间。非劣界为 −5 个百分点，下限严格高于该界、主配对全部尝试且各正式服务首尾供电和清理通过核验才确认。实际输入或缓存冲突会使确认性分析失效。存在未尝试时显示完整病例的条件性估计并单列覆盖，失败但已尝试计入分母。640 题按真实差为零、配对分歧率 25% 规划约八成功效。Q5/Q8 等其他比较和格式、内容正确率只作描述。冻结后不以结果重新挑选题目、样本数或判断阈值。
